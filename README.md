# 玉 · YU — живой нефрит

Интерактивный проект на русском и английском о нефрите и жаде: история от неолитических культур, мифология Китая, майя и маори, минералогическое различие нефрита и жадеита, а также доказательная проверка медицинских обещаний.

Сайт рассчитан на широкую аудиторию: каждый раздел начинается с короткого объяснения и позволяет открыть хронологию, слои мифа, сравнительные характеристики и точные первоисточники.

Production: [https://agent-axiom.github.io/yu/](https://agent-axiom.github.io/yu/)

English: [https://agent-axiom.github.io/yu/en/](https://agent-axiom.github.io/yu/en/)

## Локальный запуск

Требуется Node.js 24 и npm 11.

```bash
npm install
npm run dev
```

Astro напечатает локальный URL. Конфигурация проекта учитывает GitHub Pages base path `/yu`; все внутренние ссылки строятся через единый base-aware helper.

## Проверка

```bash
npm run build
npm run test:unit
npm run test:browser
npm run preview
```

- `npm test` проверяет контент, цитирования, интерактивную логику, изображения, медицинские предупреждения, маршруты, доступность и deployment workflow.
- `npm run build` выполняет строгую TypeScript/Astro-проверку и создаёт статические страницы в `dist/`.
- `npm run preview` поднимает локальный сервер production-сборки.
- `npm run test:browser` проверяет RU/EN, переключение языка, клавиатуру, no-JS, мобильную верстку и локальные шрифты в Chromium (desktop и touch). Для первого запуска: `npx playwright install chromium`.

## Редакционная политика

- Археологический контекст отделён от интерпретации символа.
- Легенда, культурный контекст и подтверждённые данные показаны отдельными слоями.
- Медицинская карточка всегда содержит уровень доказательности, ограничения и предупреждение по безопасности.
- В библиографии представлены азиатские и западные исследователи, музеи, геммологические и медицинские учреждения.
- Цвет или фотография не используются как доказательство подлинности минерала.

Полная библиография хранится в `src/content/sources` и выводится на странице `/sources/`.

## Локализация и словарь

Русские адреса не меняются, английские находятся под `/en/`. Страницы используют общие шаблоны; `localizePath` добавляет язык и Pages base, `withBase` используется только для общих файлов. Переключатель удерживает страницу, query и якорь; без JavaScript он остаётся обычной ссылкой на соответствующую страницу. Заголовки библиографических работ сохраняются на языке оригинала.

`src/i18n/content.en.json` хранит редакторский перевод по неизменным ID; отсутствие перевода вызывает ошибку сборки. Словарь содержит шесть терминов с культурным контекстом и источниками произношения. `<Term id="jade">jade</Term>` открывает определение поверх текста, а без JavaScript ведёт к статье словаря. Медицинские ограничения одинаковы в обеих версиях.

Карточки ссылок генерируются из метаданных собранных страниц: `npm run build && npm run social:generate && npm run build`. Генерация требует Chromium, готовые JPEG хранятся в git, поэтому Pages собирается без браузера. При изменении title/description карточки нужно обновить. Шрифты загружаются с того же origin, без запросов Google Fonts.

## Изображения

Документальные изображения взяты только из коллекции The Metropolitan Museum of Art с пометкой Public Domain. Атмосферные изображения созданы генеративной моделью и не выдаются за археологические фотографии или реконструкции. Полная атрибуция и перечень преобразований: [CREDITS.md](./CREDITS.md).

## Доступность

Смысловой контент доступен без JavaScript. Интерактивные шкалы и вкладки используют нативные кнопки, клавиатурную навигацию и ARIA-связи; предусмотрены skip-link, заметный фокус, адаптивная верстка и отключение анимаций через `prefers-reduced-motion`.

## Деплой

`.github/workflows/deploy.yml` использует официальный Astro workflow: checkout → build/upload → deploy-pages. Push в `main` автоматически публикует статическую сборку в GitHub Pages.
